# موقع دواجن ومشويات سمورة

## التشغيل

افتح `index.html` في متصفح حديث. الموقع يستخدم HTML وCSS وJavaScript دون تثبيت حزم. الخط العربي يُحمّل من Google Fonts، وتظهر الخطوط البديلة عند عدم الاتصال.

## لوحة الإدارة

توجد لوحة الإدارة داخل `Admin/`، ويمكن فتحها من `Admin/index.html` أو من رابط الإدارة أسفل الموقع. تشبه تنظيم لوحة موقع المعلم، وتدير:

- المنتجات والأسعار والوصف والصور والتصنيفات وحالة الظهور والعروض.
- نصوص الواجهة والأقسام والعناوين وأزرار الموقع.
- الشعار والبانر والصورة العائلية والألوان وإظهار أقسام الصفحة.
- ملفات الفيديو المباشرة وصورها، ومراجعات العملاء وصورها.
- الهاتف والعنوان وواتساب والخريطة وروابط فيسبوك وTorchman.
- استيراد ملف محتوى سابق وتصدير نسخة جديدة باسم `content.js`.

تُحفظ المسودة تلقائيًا في تخزين المتصفح المحلي، وتظهر التغييرات على الموقع عند تحديثه في المتصفح نفسه. لنقلها إلى ملفات المشروع، صدّر `content.js` واستبدل به الملف الموجود في المجلد الرئيسي. صور المنتجات والمراجعات والصور المرفوعة تُضغط وتُضمّن في ملف التصدير. أضف ملفات الفيديو إلى مجلد الموقع ثم أدخل مسارها أو رابطها المباشر في اللوحة؛ لا ترفع اللوحة ملفات الفيديو الكبيرة داخل ملف المحتوى.

## تنبيه النشر

هذه لوحة واجهة أمامية محلية، ولا يوجد فيها تسجيل دخول أو خادم أو قاعدة بيانات. أي شخص يستطيع فتح رابط `Admin/` إذا نُشر المجلد كما هو. استخدمها محليًا، أو أضف حماية وصول على الخادم قبل النشر العام. رسوم التوصيل والتوفر ما زالت بحاجة إلى تأكيد المطعم.
